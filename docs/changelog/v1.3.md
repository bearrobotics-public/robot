!!! note
    Bear Robot API v1.3 is designed to be backward compatible with v1.2, so there should not be any issues working with the v1.2 gRPC APIs.

### Minimum Robot Software Versions (for full support)

1. Servi: 26.02
2. Carti: 26.02
3. AMR: 26.02

### New RPCs

API is grouped into the following categories:

#### [Mission](../v1.3/resources/Mission.md)

- [CreateMissionBatch](../v1.3/resources/Mission.md#createmissionbatch)
- [AppendMissionBatch](../v1.3/resources/Mission.md#appendmissionbatch)
- [ClearMissionStatus](../v1.3/resources/Mission.md#clearmissionstatus)

#### [Robot Status](../v1.3/resources/RobotStatus.md)

- [SubscribeNavigationStatus](../v1.3/resources/RobotStatus.md#subscribenavigationstatus)

### Enhanced RPCs

#### Robot Status

- **[SubscribeRobotStatus](../v1.3/resources/RobotStatus.md#subscriberobotstatus)** and **[GetRobotStatus](../v1.3/resources/RobotStatus.md#getrobotstatus)** now return a `localization_state` field (field 10 on `RobotState`) carrying the robot's localization process state
- **[SubscribeRobotStatus](../v1.3/resources/RobotStatus.md#subscriberobotstatus)** and **[GetRobotStatus](../v1.3/resources/RobotStatus.md#getrobotstatus)** now also return a `navigation_state` field (field 11 on `RobotState`) carrying the robot's stuck state
