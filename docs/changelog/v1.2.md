!!! note
    The v1 API is a new surface published alongside the existing [v0.1](../v0.1/robot/RobotApiService.md) API. The v0.1 API remains supported.

### Minimum Robot Software Versions (for full support)

1. Servi: 26.01
2. Carti: 26.01
3. AMR: 26.01

### Breaking Changes

Bear Robot API v1.2 is not backward compatible with v0.1. To use the v1.2 API, users must download and compile
the new v1.2 Protobuf library. Refer to the functional comparison table below and follow the Upgrade Guide.
Contact Customer Support or your Account Manager if additional help is needed.

#### How to Upgrade

1. Review the v1.2 [API endpoint specification](../v1.2/resources/Mission.md).
2. Upgrade robot software to the compatible versions listed above.
3. Download and compile the updated v1 Protobuf library. See our Programming Guide and examples for relevant endpoints.
4. Test your integration against the new version.
